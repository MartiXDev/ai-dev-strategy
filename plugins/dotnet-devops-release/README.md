# .NET DevOps Release Plugin

Release safety package for .NET teams focused on CI/build-test gates, deployment preflight checks, and rollback-minded release discipline.

## Installation

```bash
# Using Copilot CLI
copilot plugin install dotnet-devops-release@martixdev
```

## What's Included

### Skills

| Skill | Description |
|-------|-------------|
| `dotnet-devops-release-safety` | Enforces release-safe .NET delivery with CI quality gates, deployment checks, progressive rollout controls, and rollback readiness. |

## Focus Areas

- **CI gate rigor**: release builds, deterministic artifacts, and strict test pass requirements.
- **Deployment safety**: environment preflight checks, migration readiness, and health probe validation.
- **Progressive release discipline**: staged rollout with explicit pause points and observable success criteria.
- **Rollback readiness**: verified last-known-good artifacts, trigger thresholds, and execution-ready rollback playbook.
