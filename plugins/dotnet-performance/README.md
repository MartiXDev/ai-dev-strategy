# .NET Performance Plugin

Practical guidance for improving .NET application performance through async correctness, non-blocking execution, efficient data access, caching strategy, and hotspot-oriented optimization.

## Installation

```bash
# Using Copilot CLI with your configured marketplace
copilot plugin install dotnet-performance@<marketplace-name>
```

## What's Included

### Skills

| Skill | Description |
|-------|-------------|
| `dotnet-performance` | Improves .NET performance by fixing async misuse, removing blocking calls, optimizing EF Core/data access, applying safe caching patterns, and prioritizing measured hotspots. |
