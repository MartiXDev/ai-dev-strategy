# .NET API Quality Plugin

Practical guidance for improving modern ASP.NET Core API quality with consistent validation, Problem Details error responses, OpenAPI documentation, and endpoint behavior.

## Installation

```bash
# Using Copilot CLI with your configured marketplace
copilot plugin install dotnet-api-quality@<marketplace-name>
```

## What's Included

### Skills

| Skill | Description |
|-------|-------------|
| `dotnet-api-quality` | Helps standardize validation, ProblemDetails, OpenAPI metadata, exception handling, and API response consistency for ASP.NET Core APIs. |
