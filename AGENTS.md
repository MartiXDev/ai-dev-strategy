# Agent guide

## Agent skills

### Issue tracker

This repo tracks work in GitHub Issues, and external PRs are not a triage
request surface. See `docs/agents/issue-tracker.md`.

### Triage labels

This repo uses the default five-label triage vocabulary with no overrides. See
`docs/agents/triage-labels.md`.

### Domain docs

This repo uses a single-context layout with root `CONTEXT.md` and `docs/adr/`.
See `docs/agents/domain.md`.
