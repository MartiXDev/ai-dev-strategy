# Requirement Pack: Spec-Driven Overnight Workflow

Treat the request as part of an overnight implementation pipeline:

1. Start from explicit feature intent and constraints.
2. Produce artifacts that demonstrate continuity from planning to implementation:
   - A concise feature specification (`docs/specification.md` or equivalent).
   - A technical plan (`plans/technical-plan.md`).
   - A task list (`plans/tasks.md`) linked to the plan.
3. Then generate implementation files under `code/` that follow those artifacts.

Use a spec-driven style similar to constitution/spec/plan/tasks flows.
Prefer deterministic, auditable outputs over ad-hoc prose.
